元数据同步

请按步骤手动执行：① 初始化 → ② 扫描 → ③ 确认元数据 → ④ 同步到元数据库 → ⑤ 在「向量库同步」构建索引。暂存区已有未同步数据时，② 扫描视为已完成（标绿），可直接去编辑。

同步范围

增量写入（Upsert），支持全库 / 单表；单字段请在「元数据编辑」保存时同步。同步成功后对应暂存记录会清空，需重新扫描才能再次编辑。

扫描（含重新扫描）会先清空整个暂存区，再写入本次扫描结果；指定表扫描时暂存区仅保留该表。指定表列表来自业务库，无需先全库扫描。

元数据编辑 · 确认元数据

扫描后在此核对/修改表与字段说明（必填，仅写入元数据库，不会修改业务源表）。若 L1 已有同名表/字段说明，可点 一键匹配元数据库 继承到暂存。可按表 AI 补全；向量索引请在「向量库同步」构建。

推荐流程：扫描 → 逐表保存到暂存 → 确认无误后点「同步到元数据库」一次性写入 L1（不支持逐表同步）

同步为增量 Upsert：将当前暂存区全部表/字段写入元数据库，未在暂存中的 L1 记录默认不改动（含 is_enabled）。 写入成功后暂存区清空。再次维护请先扫描。

表 JOIN 关系

JOIN 无暂存区：点「保存」后直接写入元数据库；下方列表即为已保存的关系。 「启用」= 参与召回与 M-Schema；取消启用或删除时，会自动清理向量库中对应的 JOIN 向量。 批量向量化请至「向量库同步」，选「仅 JOIN」或「全库」构建。

业务指标

保存后直接写入元数据库。批量向量化请至「向量库同步」，选「仅指标」或「全库」构建。

同义词映射

口语 → 表/字段，问数召回会即时读取。字段同义词会写入该列的 synonyms，便于向量索引。保存后无需改代码。
