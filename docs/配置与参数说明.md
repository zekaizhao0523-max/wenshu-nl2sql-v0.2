# 配置与参数说明

| 属性 | 内容 |
|------|------|
| 版本 | v1.0 |
| 更新日期 | 2026-08-28 |

本文汇总问数平台 **环境变量**、**评测脚本参数** 与 **UI 可覆盖项**，并给出调参建议。模板见仓库根目录 [`.env.example`](../.env.example)。

**优先级**：`.wenshu/connections.json` / `.wenshu/model_settings.json`（UI 保存）> 进程环境变量 > `.env`。

---

## 1. 数据库与向量库

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `MYSQL_HOST` / `PORT` / `DATABASE` / `USER` / `PASSWORD` | 见 example | 业务库（RAW）连接 | 生产用只读账号 |
| `RAW_MYSQL_*` | 继承 `MYSQL_*` | 显式指定 RAW 库 | 业务库与元数据库分离时设置 |
| `META_MYSQL_*` | 见 example | L1 元数据库 | 与 RAW 分库、分账号 |
| `META_MYSQL_DSN` | 空 | 完整 SQLAlchemy DSN | 可替代分项配置 |
| `QDRANT_URL` | `http://127.0.0.1:6333` | Qdrant 地址 | 远程部署改 URL |
| `QDRANT_COLLECTION` | `wenshu_knowledge` | 集合名 | 多环境用不同 collection |
| `QDRANT_API_KEY` | 空 | Qdrant 鉴权 | 云 Qdrant 必填 |

## 2. Embedding 与 LLM

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `EMBEDDING_PROVIDER` | `local` / `openai` | 向量提供方 | 本地开发用 `local`；线上可用 API |
| `LOCAL_EMBEDDING_MODEL` | `Qwen/Qwen3-Embedding-0.6B` | 本地模型名或路径 | 与 `EMBEDDING_DIM` 一致 |
| `EMBEDDING_DIM` | `1024` | 向量维度 | 换模型必须同步改维度和重建索引 |
| `LOCAL_EMBEDDING_DEVICE` | `cpu` | `cpu` / `cuda` | GPU 可显著加速 index |
| `EMBEDDING_MODEL` / `EMBEDDING_API_BASE` / `EMBEDDING_API_KEY` | — | OpenAI 兼容 Embedding | API 模式 |
| `LLM_PROVIDER` | 自动推断 | `ollama` / `openai` | 见 `wenshu/services/model_config.py` |
| `OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Ollama 地址 | |
| `OLLAMA_MODEL` / `LOCAL_LLM_MODEL` | `qwen3:4b` | 生成模型 | 越大通常 SQL/计划更稳，更慢 |
| `LLM_MODEL` / `LLM_API_BASE` / `LLM_API_KEY` | — | API LLM | 生产推荐 |

**调参原则**：召回质量主要取决于 **L1 注释质量 + Embedding**；Agent 质量主要取决于 **LLM 能力**。换模型后建议重跑 `recall_eval` 与 `run_sql_eval` 小样本冒烟。

## 3. Schema 召回

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `SCHEMA_RETRIEVAL_STYLE` | `xiyan` | `xiyan` 多路检索 / `legacy` 整句单向量 | 生产保持 `xiyan`；对比基线可设 `legacy` |
| `SCHEMA_KEYWORD_MODE` | `auto` | 关键词抽取：`auto`（LLM 失败回退 rule）/ `llm` / `rule` | 离线评测常用 `rule` 可复现；线上 `auto` |
| `SCHEMA_INTENT_MODE` | `rule` | 意图分类（聚合/排序等） | 一般不需改 |
| `SCHEMA_CLARIFY_GATE` | `1` | 缺槽时暂停并追问 | 批量评测可关：`0` 或脚本 `--no-clarify-gate` |
| `SCHEMA_COLUMN_SELECT` | `1` | LLM S1/S2 两轮选列 | 关则列池变大、噪声多；**建议保持开** |
| `SCHEMA_COLUMN_SELECT_TIMEOUT` | `25` | 选列 LLM 超时（秒） | 慢模型可适当加大 |
| `XIYAN_SEARCH_MAX_WORKERS` | `8` | 多短语并行检索线程数 | CPU 紧张时调小 |

代码内 XiYan 常量（一般不改，改完需回归评测）位于 `wenshu/services/schema_retrieval.py`：`XIYAN_KEYWORD_TOP_K`、`XIYAN_TABLE_SCORE_POOL`、`XIYAN_JOIN_POOL` 等。

### 3.1 召回相关 API / 脚本参数

| 参数 | 位置 | 含义 |
|------|------|------|
| `limit` | `retrieve_schema` / 评测 `--limit` | 列池上限（默认 30） |
| `keyword_mode` | API body / `--keyword-mode` | 同 `SCHEMA_KEYWORD_MODE` |
| `column_select` | API body / `--column-select` | 同 `SCHEMA_COLUMN_SELECT` |
| `retrieval-style` | `run_recall_eval` / `run_sql_eval` | `xiyan` 或 `legacy` |
| `ks` | `run_recall_eval` | Table/Column Hit@K，如 `5,10,15,30` |

**调参路径**：

1. Table@10 低 → 补 L1 表说明、`sample_questions`、同义词；检查 JOIN 边
2. Column@10 低但 Column@30 高 → 列池够、排序靠后；优化 S2 或 P1 前排逻辑（代码侧）
3. S2 明显差于 S_rtrv → 调 LLM 或缩列池噪声

## 4. 问数 Agent

### 4.1 运行与安全

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `AGENT_APPROVAL_ENABLED` | `1` | 敏感 SQL 需人工审批 | 本地调试可 `0`；生产保持 `1` |
| `AGENT_SKIP_SANDBOX` | `0` | 跳过只读执行 | 仅生成 SQL 时设 `1` |
| `AGENT_SQL_TIMEOUT_MS` | `30000` | 沙箱单条 SQL 超时 | 复杂查询加大 |
| `AGENT_SQL_MAX_ROWS` | `200` | 返回行数上限 | 与 `QueryPlan.limit` 对齐；过大影响性能 |
| `AGENT_EXPLAIN_ROW_THRESHOLD` | `1000000` | EXPLAIN 行数预警阈值 | 风控用 |
| `AGENT_DATA_SCOPE` / `AGENT_DB_SCOPE` | 空 | 数据范围注入（校验层） | 多租户场景配置 |

### 4.2 QueryPlan（计划生成）

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `AGENT_PLAN_LLM` | `0` | 强制所有题走 LLM 计划 | 调试 StructAcc 时可 `1`；线上默认规则+复杂题 LLM |

计划重试次数由 API / 评测参数 `max_plan_retries`（默认 2）控制，非环境变量。

### 4.3 SQL 生成 — 默认路径（对齐 icecoding M7→M8→M10）

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `AGENT_SQL_MULTI_CANDIDATE` | `1` | 首轮是否多候选 LLM | 关则只生成 1 条，速度快、多样性低 |
| `AGENT_SQL_CANDIDATE_COUNT` | `2` | 首轮候选条数（1–3） | 增至 `3` 略提质量、增 latency 与 token |
| `AGENT_SQL_LLM` | `0` | 跳过确定性编译，强制 LLM SQL | 评测对比或计划难编译时试 `1` |

**行为摘要**（`sql_generation.py`）：

- QueryPlan 可确定性编译 → **直接返回**，不混 LLM 候选
- 否则首轮 N 条 LLM → **AST 静态打分**选最优
- M8 校验失败 / M10 执行失败 → 重试轮优先复用未选中候选，否则单条 LLM + 错误反馈

### 4.4 SQL 生成 — 可选 XiYan 流程

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `AGENT_SQL_XIYAN_PIPELINE` | `0` | 开启 S1/S2 双 schema + 执行聚类选优 | 与 icecoding 默认不同；A/B 时设 `1` |
| `AGENT_SQL_EXEC_SELECT` | `0` | 旧开关，`=1` 等同开启 XiYan 流程 | 建议只用 `AGENT_SQL_XIYAN_PIPELINE` |
| `AGENT_SQL_ENSEMBLE_LLM` | 空 | XiYan 下是否追加多策略 LLM | 空=随 XiYan 开关；可显式 `0` 关 LLM 只留确定性 |

**XiYan 流程摘要**（`sql_ensemble.py`）：

1. 确定性编译 + S1/S2 双路 schema × 多策略 LLM → 候选池
2. 静态校验过滤
3. 执行失败 self-refine 再生成
4. `sql_exec_select`：**沙箱执行 + 结果聚类**选最优 SQL

DWD77 参考：XiYan 流程 ResultAcc **47.0%** vs 默认 icecoding 路径需单独复测对比。

### 4.5 结果解读

| 变量 | 默认 | 含义 | 调参建议 |
|------|------|------|----------|
| `AGENT_RESULT_SUMMARY_MODE` | `auto` | 结果自然语言解读模式 | `off` 可关 M11 省 token |

## 5. SQL 联合评测脚本（`run_sql_eval.py`）

| 参数 | 默认 | 含义 |
|------|------|------|
| `--golden` | 必填 | 黄金集 jsonl 路径 |
| `--ks` | `5,10,15,30` | 召回 Hit@K |
| `--limit` | `30` | 列池 limit |
| `--retrieval-style` | `xiyan` | 召回风格 |
| `--keyword-mode` | `rule` | 关键词模式（评测可复现） |
| `--column-select` / `--no-column-select` | 开 | S1/S2 选列 |
| `--clarify-gate` / `--no-clarify-gate` | 关 | 评测通常关闭澄清 |
| `--with-result-acc` / `--no-with-result-acc` | 开 | 方案 A：双跑 gold/pred 比结果集 |
| `--force-llm-sql` | 关 | 等同 `AGENT_SQL_LLM=1` |
| `--max-plan-retries` | `2` | 计划最大重试 |
| `--max-sql-retries` | `2` | SQL 最大重试 |
| `--max-items` | `0` | 只跑前 N 题（冒烟） |
| `--out` | 自动 | 报告路径 |

**环境变量与脚本关系**：评测进程会 `load_dotenv()`，可在运行前 `export AGENT_SQL_XIYAN_PIPELINE=1` 切换 SQL 路径，无需改代码。

## 6. 推荐配置组合

### 6.1 本地开发（默认）

```env
SCHEMA_KEYWORD_MODE=auto
SCHEMA_COLUMN_SELECT=1
AGENT_SQL_MULTI_CANDIDATE=1
AGENT_SQL_CANDIDATE_COUNT=2
AGENT_APPROVAL_ENABLED=1
AGENT_SKIP_SANDBOX=0
# AGENT_SQL_XIYAN_PIPELINE=0
```

### 6.2 离线批量评测（可复现）

```env
SCHEMA_KEYWORD_MODE=rule
SCHEMA_CLARIFY_GATE=0
```

```bash
python evals/scripts/run_sql_eval.py \
  --golden evals/golden/recall_v2_dwd.jsonl \
  --keyword-mode rule \
  --no-clarify-gate \
  --column-select
```

### 6.3 试 XiYan 执行选优

```env
AGENT_SQL_XIYAN_PIPELINE=1
AGENT_SQL_ENSEMBLE_LLM=1
```

### 6.4 仅调试 SQL 文本（不执行）

```env
AGENT_SKIP_SANDBOX=1
```

或在 Web「问数 Agent」勾选「仅生成 SQL，不执行沙箱」。
